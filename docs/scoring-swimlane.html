Informasi Tambahan — Alur Follow-Up Question & Score Protection

Jika nilai jawaban utama (Technical atau SoftSkill) berada di bawah threshold (Confidence < 0.75 ATAU Similarity < 0.65 ATAU Rubric < 0.70), sistem secara otomatis memicu pembuatan follow-up question.

Score Protection Formula:
Skor akhir dihitung ulang untuk menjamin nilai kandidat tidak pernah turun setelah menjawab follow-up:
updatedConfidence = mainConfidence * 0.70 + followUpConfidence * 0.30
updatedFinalScore = max(finalScore, finalScore * 0.85 + followUpScore * 0.15)

Jawaban follow-up dinilai secara mandiri menggunakan komponen scoring yang sama (rubric, similarity, keyword) tanpa membuat record Score baru. Nilai utama kemudian di-update dan log data follow-up disimpan di dalam array followUps pada JSON breakdown.
